# 📚 Book Recommender System (BookVerse AI)

An intelligent, collaborative filtering book recommendation engine built with Flask, NumPy, and Pandas.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/masumganvir/book_recommendation_system)

## ⚡ 1-Click Deployment on Render

Click the button above or use this direct link:
**[https://render.com/deploy?repo=https://github.com/masumganvir/book_recommendation_system](https://render.com/deploy?repo=https://github.com/masumganvir/book_recommendation_system)**

Render will automatically detect `render.yaml` and configure:
- Python 3.11.9
- Free web service plan
- Automatic build (`pip install -r requirements.txt`)
- Production WSGI server (`gunicorn`) with memory optimization
- Health check monitoring (`/health`)

## 🚀 Keeping the App Awake 24/7 (No Sleep / No Cold Starts)
Render free services spin down after 15 minutes of inactivity. To prevent sleep and keep the app instantly available 24/7:
1. Copy your live Render URL (e.g. `https://your-app.onrender.com/health`).
2. Add a free 10-minute ping monitor on [cron-job.org](https://cron-job.org/) or [uptimerobot.com](https://uptimerobot.com/).
